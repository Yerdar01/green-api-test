# GREEN-API Test Task

Интерактивный веб-интерфейс для работы с методами REST API сервиса **GREEN-API**. Проект выполнен в рамках тестового задания на вакансию «Специалист технической поддержки 2 линии».

## 🚀 Функциональность

Приложение позволяет отправлять запросы к API и получать форматированный JSON-ответ в реальном времени:

* **getSettings** — получение текущих настроек аккаунта.
* **getStateInstance** — проверка состояния авторизации инстанса.
* **sendMessage** — отправка текстовых сообщений в WhatsApp.
* **sendFileByUrl** — отправка документов и медиафайлов по прямой URL-ссылке.

## 🛠 Технологический стек

* **HTML5 / CSS3** — чистая двухколоночная верстка строго по предоставленному макету.
* **Vanilla JavaScript (ES6+)** — использование `async/await` и `fetch` без сторонних фреймворков и библиотек.

## 🔒 Безопасность и валидация

* **Защита учетных данных:** Поля `idInstance` и `ApiTokenInstance` вводятся пользователем вручную и не хранятся в коде или репозитории. Поле токена замаскировано (`type="password"`).
* **Обработка данных:** Реализовано автоформатирование номеров телефонов (автоматическая подстановка `@c.us`) и валидация передаваемых URL-ссылок.
* **Архитектурное замечание:** Запросы выполняются напрямую с клиента (Client-Side) в рамках условий тестового задания. В продуктовой среде вызовы API с использованием токенов должны проходить через Backend Proxy.
